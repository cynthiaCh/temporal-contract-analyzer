From a task to reusable experience

  1. Configure. Choose training or testing, case range, model profile, and your pinned execution environment.
  2. Prepare. The existing preparation CLI freezes inputs and checks evaluators without model requests.
  3. Start. The workbench schedules the public tempoevo run --execute CLI, with up to eight different cases concurrently.
  4. Inspect. Read actual contracts, submitted edits, evaluator verdicts, and candidate experience.
  5. Review. Publish a retained candidate to the review queue, then use Experience Review for an actual human decision. Neither operation runs automatically.

Training allows up to three repair Actions. Testing uses one Action, an independent final Gold score, and frozen memory. A finished queue can contain failures or execution errors.

python3 -B -m temporal_contract_analyzer tempoevo publish-candidate success \
  --root PATH_TO_TRAJECTORY

python3 -B -m temporal_contract_analyzer experience-memory review \
  --store experience-memory/library
