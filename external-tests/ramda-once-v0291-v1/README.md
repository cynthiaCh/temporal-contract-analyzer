固定来源：[`ramda/ramda` v0.29.1，提交 `acbf91af8a3b39e22d3a1f24d068356891797851`](https://github.com/ramda/ramda/blob/acbf91af8a3b39e22d3a1f24d068356891797851/source/once.js)，2023 年版本。文件含注释共 36 行，核心包装逻辑约 12 行；运行保留 _arity、_curry1、_isPlaceholder 三个真实库内辅助模块，无第三方运行依赖。

## 结果：工具 0.6.6 未修改

原版的入口判断位于 L28，called 标志在 L31 写入，用户函数在 L32 调用。人工变体只交换标志写入与结果计算两句，变为 L31 调用、L32 写标志。默认卡引用这个顺序变化；两侧均能解析，输入使用相同工具摘要，工具无需为本例添加规则。

结论：现有分析器在这个新的项目/固定版本上，能区分已知模式下的一个人工时序退化。**这不是发现上游真实缺陷，也不证明总体准确率、跨领域泛化或 LLM 收益。** 原版不报警只是所建模关系的结果，不表示全程序安全。

## 人工变体

原版：

```js
called = true;
result = fn.apply(this, arguments);
```

变体：

```js
result = fn.apply(this, arguments);
called = true;
```

除交换这两句之外，入口、返回值缓存和辅助模块保持不变。回调同步调用自己的包装入口一次，原版只执行一次，变体执行两次；普通顺序调用和微任务重入两侧都只执行一次。变体是研究者构造的单个控制，不算独立真实开源缺陷。

## 范围、选择与验证

- 先看项目体量与源码，再固定版本，然后扫描。最先检索的 maxmechanic/once 从树结构可见是浏览器扩展，因用途不符排除。Ramda 当前源码加入了异常保留逻辑，选择旧 v0.29.1 是为了缩小实现和验证范围；选择完成之前没有运行候选分析。不宣称盲测。
- 当前文件未参与规则修改，但属于此前一直测试的 once 功能家族，且为人工重排控制，不能把结果当成广泛独立验证集。
- 分析器只接收 once.js，不读取测试、上游修复、辅助模块内容或运行结果来产生提示。该范围没有证明 _arity/_curry1 的完整动态调用图；实际执行则加载固定的真实辅助模块，用运行检查确认行为。
- 8 项自写 Node 检查覆盖：普通重复调用与缓存、参数转发、this、参数个数、零参/placeholder 柯里化、包装器独立性、同步重入、微任务重入。保存了上游 test/once.js 的 4 个 Mocha 用例，但没有安装整套开发依赖或运行上游全套测试；8 项结果不冒充上游套件结果。
- Node v24.21.0 在临时 ESM 测试上下文中直接执行原始模块和三个辅助模块，不 mock、不转译、不安装 npm 包。仅临时 package.json 指定 type=module；候选字节不变。
- MIT 许可证、原文件及出处都有哈希记录。工具核心实现的 git diff 为空，工具摘要与上一轮 @ungap/once 0.6.6 记录相同。
