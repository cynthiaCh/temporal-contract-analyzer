提交 Git 仅表示保存版本，不表示审核、接受或验证迁移有效性。原 37 条已审核分类经验及其冻结快照保持不变；这些候选不进入默认正式检索。本目录是只读历史归档，审核现行候选应在分类库记录，不回写原训练快照。
