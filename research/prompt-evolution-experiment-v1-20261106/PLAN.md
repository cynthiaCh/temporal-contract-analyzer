# 两轮评分反馈驱动的 prompt 演化小实验

日期：2026-11-06。范围仅为独立研究目录，不改生产、评分器、RAG、题库或既有档案，不创建提交。沿用修正后的单Agent CLI工具循环与bwrap隔离，无多Agent协作、无新依赖。

问题：自动利用开发评分和真实执行证据改写固定执行说明，能否提高修复，并迁移到优化器未见的任务？主假设允许正、零、负结果。反例：开发集得分提高但留出集无增量/退步，即开发拟合，不能说总体能力提升。

P0是上轮B.md的流程正文，记录限制拆为两组共用的RECORD_GUARD.md；正文和记录要求本身未改，仅重新分块。比较P0与自动选出的P*，不是上一轮自主A。固定原任务、候选、源码BM25、固定五题及顺序；AST交付均关闭。修复模型、优化模型均gpt-6-sol/low；每调用600秒；workspace-write、approval never；无新增输出token限制。阶段仍为提示词约束，外层只控制prompt演化和选取，不强制阶段语义。

开发集：download-polling-restoration-low-cue-react18、transfer-progress-composition-v4-vanilla。选择依据为上一轮真实B失效与重复不稳定，不使用同源变体。优化器留出集：document-submit-snapshot-vanilla、local-config-readiness-low-cue-vue2；与开发集不同source unit，覆盖提交/归档重入和组件API就绪。来源全部研究暴露，文档题为authored extension；独立泛化案例数0。留出指对本轮优化器隔离，并非过去未运行。最近附加材料条件在这两题有通过天花板风险；不得为制造失败更换案例、降低模型或移除材料。

调用上限16，不重试、不扩容：开发P0两题各一次=2；改写调用1=1；开发P1两题各一次=2；改写调用2=1；开发P2两题各一次=2；留出两题×P0/P*×2次=8。两轮改写串行，第二轮只看开发集的已完成反馈和当前最优正文。候选无效时占用改写预算，相应开发槽位跳过且不补齐。即使未选中新候选，仍按冻结计划做P0/P*的独立重复，明确P*等于P0，不能称优化成功。

优化输入仅有：开发原任务、可见原始源码、当前正文、已评估开发候选正文、修复补丁、真实工具轨迹摘录和行为评分摘要（整体、required布尔、forbidden、原通过项丢失）。不提供评分器源码、参考补丁、隐藏测试输入/断言、留出案例名/源码/成绩或上轮完整研究报告。评分摘要是本轮新授权的开发反馈通道；修复调用本身仍无评分反馈。优化器在独立挂载空间读packet，无研究目录访问权。

优化器只输出可复用执行说明（上限5000 Unicode字符），不得把已见案例ID、路径、标识符、检查ID、参考代码或答案写成prompt。保留三阶段目标，可调整核查/不确定性/验证要求；记录约束为所有修复条件共同固定后缀。机械卫生检查仅拒绝明确泄漏/越界内容，不代表语义正确。失败或越界候选不人工重写、不另起调用重试。

自动选择规则在看结果前冻结：只有两道开发题都可信评分、无禁止效果、无相对当前最优的已通过检查项丢失，且(整体PASS数, required通过总数)按字典序严格增加，才替换当前最优。平局保留旧版；不因token/时间噪声选胜者。不用留出结果选prompt或再改第三轮。只有一份开发运行/题，选择有采样偏差，成绩是训练/选择内结果。

先完成离线检查和4案例×原样/参考=8次无模型校准，再启动正式调用。先冻结案例、材料、起点、P0、优化指令、卫生规则、选择逻辑、修复运行器、预算和调度；每个新候选在其开发评分前落盘并记录摘要；P*在留出前冻结。留出配对按种子2026110601交错，第二次反转组顺序；无可控模型采样种子。

指标：开发每轮整体/required/forbidden/原通过项丢失及选择决定；留出逐题逐重复整体、检查得失、额外无依据行为；输入/缓存/输出token、壁钟时间、工具调用、记录长度、超时/执行失败/评分异常。搜索与优化成本单列，不能只报最终prompt执行成本。轨迹、补丁和验证支撑过程解释；不以模型自述或格式为真值。小样本不作显著性或总体泛化结论。

停止：最多两次改写，完成预定留出即结束。运行故障保留，不静默重试。遇到共同设施故障则停止并记录，不能一边看留出一边调流程。预定结论可能是未找到更优prompt、仅开发拟合、留出无变化、出现回归，或观察到有限迁移。

交付：协议/来源/材料摘要，P0/P1/P2/P*，优化packet和输出、dev/holdout各独立工作区、提示/轨迹/阶段/补丁/用量/可信评分，选择收据，summary.json、REPORT.md、验证记录、建议commit subject/body；不提交。
