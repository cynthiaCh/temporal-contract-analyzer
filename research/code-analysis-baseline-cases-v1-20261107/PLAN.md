## 预算、顺序与停止

最多6个顶层 CLI 分析会话，3例×2次。每会话600秒，最多12次原生模型请求；全实验最多72次原生模型请求，零反思／judge／冒烟模型请求。原生请求以同步 PreModelRequest/PostModelRequest 记录，不把CLI会话或tool item数当模型请求数。每个meter只允许本槽12次，六槽各启动一次，因此合计硬上限72；runner另核对汇总。禁止自动恢复、重试、补跑、续写或扩规模；失败槽保留缺失。计数器不可确认立即停后续。达到请求上限后试图再发请求，在 dispatch 前 kill；不使用模型预跑验证计数器。网络包／重连不另充当成功模型请求，原生钩子计数范围在报告说明。

调度种子2026110708，仅用于排列，不是采样种子。顺序固定：重复1 C1/a01、C2/a02、C3/a03；重复2 C2/a04、C3/a05、C1/a06。各重复覆盖三例，交错独立执行。六槽全部结束后才做语义评价，不因结果更改输入、标准、配置或计划。
