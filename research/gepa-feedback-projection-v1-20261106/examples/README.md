# Historical record projection examples only

All20 job folders replay existing train records from the first official GEPA study. No jobs were executed here. Each single-record prompt uses the exact skill that produced that original job, with the unchanged reflection template. These are projection examples, not actual new GEPA requests.

paired-reflection-inputs/batch-01..05 replays only the ten selected-parent records that actually entered the five historical reflections. F0 is byte-identical to those archived prompts. F1 is an unsent counterfactual feedback input.

research-evidence holds research-only raw-score pointers and explicit audited parent-child comparisons. It is never executor-visible. Such child comparisons are not automatically added to the normal selected-parent reflection dataset.
