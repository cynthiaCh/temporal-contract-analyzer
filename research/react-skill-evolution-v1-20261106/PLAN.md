# 第一轮 ReAct 执行 + 时序契约技能自演化

2026-11-06。此计划与初始技能、执行规则、公共输入、调度模板在正式模型调用前冻结。不预设流程或技能演化有益。独立研究目录；不改生产prompt/分析器/AST/评分/原题库/历史，不提交，不装依赖。

## 研究增量与范围

Codex原本就有选择工具、读取观察、修改和自检的工具循环。本轮外层新增同步PostToolUse状态/证据处理、有限PreToolUse修改前检查和Stop任务完成检查，通过本机已有hooks实现，同一CLI进程/同一Agent会话，不为每一步重启Agent。A为原自主执行+K0（相同被动hook记录），B为外层控制+K0，C为外层控制+K*。原生工具能力和权限各组一致；只有外层规则是否生效及技能字节不同。此处不是实现完整语义状态机：外层机械检查可核对引用/观察/补丁/验证存在性，语义判断仍由执行Agent承担，shell操作分类也有限。

外层以collect、inspect、repair_validate记录状态，允许至多2次显式回退。工具输出不被hook替换/隐藏；PostToolUse追加有界反馈，基于真实返回、状态和候选文件快照处理证据缺口。修改前要求有实际源码观察及引用/顺序检查；上限2次修改门拒绝，随后记录未满足状态而不无限卡住。Stop检查维护状态、实际改动、修改后真实验证记录；不强制diff，允许有依据no_change或明确incomplete。只答辅助问题不满足完成门；至多2次同会话Stop继续，耗尽后如实标为未满足。输入/输出/控制器判断均归档，不以模型“已检查”作证。

## 模型、限制、预算

固定gpt-6-sol / low，600秒/正式执行槽位，workspace-write、approval never；同前轮CLI、命令工具、系统Node及评分Node v16.20.2、输出限制（无新增输出token硬上限）。hook脚本标准库实现，不调用额外模型。使用经过本轮代码审查的独立hooks定义，以CLI一次性hook trust选项加载；不改用户全局设置或放宽工具权限。各组均加载相同hook实现和被动观察事件；A/evolver只记录，不注入控制文本。

最多18个正式CLI模型执行槽位，原生工具续轮和有界Stop续行仍在该次Agent会话内；记录底层Pre/PostModelRequest次数、重试、Stop续行和全部成本，不把它们隐藏为零成本。没有预跑模型调用、额外搜索模型、审查模型或Agent委派。开发最多6：K0两开发任务各一次（显式控制）；进化器一次；卫生/泄漏审查通过后K1两同起点任务各一次；第6个预留默认不用。保留最多12：2任务×A/B/C×2重复。若K*=K0，在最终评估启动前冻结同字节决定并取消C四槽位，不为消耗预算另造候选。同一次失败不补跑；基础设施严重异常可停止剩余槽位，不隐瞒失败，不扩容。

最多实际计划17槽（5开发+12保留），1显式预留不自动动用。K1卫生不通过则跳过两开发槽，仍保留K0；K0开发评分不可验证则停止演化，不根据未知成绩选择。

## 固定公共材料与技能

原任务+原候选冻结快照、原有纯源码BM25 RAG（沿用实现与参数）+原固定五题与顺序，各组公共材料逐字节相同。AST交付各组关闭，生产AST代码/规则保持不变。使用固定BASE.md。初始K0.md仅聚焦结果归属和副作用有效性，来源是可见题库TCQ-002/004及既有诊断的执行/核查边界，不含案例标识、隐藏信息或具体补丁。

进化对象仅K0技能正文。K1最大5000字符，保留S1...S6覆盖面；进化器自动输出skill与修改元数据（失败依据、修改步骤、预期可观察行动、保留行为风险）。正文禁止案例ID、路径/文件名、项目符号、隐藏检查ID、oracle信息、硬编码值/答案、代码示例/参考修复步骤。卫生检测+研究者逐项泄漏复核；有问题则拒绝且不启动K1，不手工修复候选。元数据可引用开发packet，不能作为技能交付给执行者。

反馈包只含两开发原任务/原源码、当前K0、实际prompt/命令/输出/候选补丁/控制观察、本轮可信评分的匿名布尔向量及原通过项丢失。隐藏断言、oracle标签/实现、参考补丁/输出细节/索引、案例专用答案、历史结果不进入技能或执行材料。匿名反馈映射仅研究侧，优化器不可见。开发原始可见源码与执行补丁允许用于学习，但新技能必须机制级通用，无具体修补指令。

## 技能接纳（只用开发）

两任务K0/K1均需可信评分。K1不得有原样已通过检查/断言丢失、禁止效果、或任一K0已通过检查/断言丢失；未回应维护任务/未落实交付亦拒绝。通过上述保留门后，仅当整体通过任务数严格增加才接纳。整体平局保留K0，不用总检查数抵消退步，也不靠单次成本波动选技能。成本作为次要描述和实践限制，不宣称两个开发样本证明稳定优越。若K0两题均全过，允许K1因天花板被拒绝，不额外找题。

## 完整prompt模板与调度

每次实际完整prompt单独归档并摘要，A/B-K0完整内容在准备时写入。组合：common.md + BASE.md + <temporal-contract-skill>技能原文</...>；A到此结束，B/C再加CONTROL.md。开发两技能均用B执行。优化器完整EVOLVER.md固定，只挂开发白名单packet。K1/C的未知正文不可在生成前伪称已经存在：其组合模板/边界现冻结，候选生成后先审查并冻结实际prompt，选择后在任何保留运行前冻结K*、A/B/C实际完整prompt与C取消决定。

调度种子2026110603仅排序，非模型采样种子。开发每技能固定随机化两案例次序，K1仍同冻结起点。保留先按rep/case配对交错，对每个case第一重复随机A/B/C，第二重复反转；若取消C，仅从预定顺序删除C，其余不改。调度表在首次调用前保存；执行中不共享中间结果。无根据前几个结果修改方案，保留结果从不进入进化器。

## 离线核查及预定分析

首次调用前：完整公共材料/配置/候选摘要一致，来源拆分有效，状态和session记录可追踪；合成源码读取/修改/验证/缺口/回退/Stop继续/有依据不修改与显式未完成检查；真实CLI hooks配置读取（无模型）；隔离中原仓库/其他运行/隐藏评分不可见；CLI/helper可运行；4案例原样/参考8个无模型可信评分校准。技能/父版本/修改元数据/实际交付字节归档。合成hooks测试不冒称真实模型链已验证。

主要：整体行为通过、原通过项（检查及场景断言）丢失、实际维护任务交付、不必要行为变化。辅助：输入/缓存/输出token、耗时/工具数、controller反馈/阻断/续行和额外请求、全部开发进化搜索成本、无效循环/证据误用/无补丁交付。先可信评分再审实际工具与patch；不能以阶段记录代替行为。A/B比较流程，B/C比较技能；K*=K0则后者不可估计。全部失败、超时、验证异常/退步单列。一次演化和少量已暴露任务仅描述，无因果/显著性/普遍泛化/自动学会的结论。
