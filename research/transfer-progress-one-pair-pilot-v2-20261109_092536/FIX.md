本版从当前候选 JS/Python/Markdown 与 TASK 生成确定性的源码片段目录。每个非空片段至多 80 字符，拥有不含案例身份的 ID；目录绑定文件摘要、原行号及精确列范围。两个案例分别生成 schema，证据字段只能选择该目录中的 ID。

模型输出仍保留 Contract、分类、全部前提状态、声明和自查，只把三处 evidence 对象数组改成 evidence_ids。模型不再重复写文件、行号或引文。原始对象在解析后、派生前单独保存；原始 CLI 流始终先于解析归档。Python 重建同一目录、验证冻结摘要与 ID 后，确定性生成原路由器兼容的引用字段。没有搜索相似引文、回填旧行号、修改规则含义或补业务依据。

派生 analysis.json 明确标为程序派生产物，raw-analysis-object.json 是原始模型对象。Contract、类别、事实状态和声明均逐字段原样保留；analysis-derivation.json 记录所选精确片段与摘要。引用合法不等于支持语义，后续仍需执行 Agent 的源码/文档核查；没有新增人工批准或额外模型评委。
