# Request dashboard

`src/controller.js` connects the view to the request service. `service.fetch`
returns a promise. Some service errors carry a boolean `retryable` property.
The host supplies timers with `schedule(callback, delayMs)` and `cancel(handle)`.

The reporter feeds the failed-load dashboard; its records represent final load
outcomes, rather than per-attempt transport diagnostics. The rendering adapter
updates the currently displayed view.

The search preview is a separate component in `src/search-preview.js`.
