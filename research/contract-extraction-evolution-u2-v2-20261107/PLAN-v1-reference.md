# U2 Contract 提取：一次反思更新

AI 辅助开发实验，不是独立人工复核或 GEPA 复现。只用已暴露 U2。原标准、映射、评价、生产技能、业务代码、评分器保持，不创建提交。

Task 1：复用 O1–O7，先冻结 evaluation-v1.csv。O1/O3按任务义务判断；其他项只评价事实、来源、未知，不把隐藏额外规格当必答。O4单列已排队timer后的关闭边界T1–T4；区分原前台、相邻后台和未来改写，不预判必须取消。五维分别评价，无总分。

Task 2：gpt-6-sol/low，K0两次独立提取；研究侧逐条评价后一次无工具、单底层请求反思。反思允许使用开发反馈，K1仅可复用方法，不含案例名/文件名/隐藏断言/专用答案。候选原样保存，不润色、不再生成。离线发现阻断就拒绝并停止；相同K1取消重复条件。

Task 3：仅替换技能文本的K1两次提取，输入源码/任务、外围协议、工具权限、模型和预算完全同K0。按同一规则检查收益、丢失、新增无据要求及timer关系，不用长度或措辞打分。不存在净改善也如实停止，K1不自动接纳为生产版本。

预算：最多5个顶层会话，提取每会话600秒/12底层请求，反思600秒/1请求，总上限49。同步PreModelRequest/PostModelRequest钩子计数；transport retry关闭，失败请求后禁止重试，越界先杀进程。另计工具调用/请求用量/实际耗时；价格未校验时美元成本未知。无模型预跑、自动重试、补跑、K2或扩搜；失败槽位保留。

隔离：bubblewrap仅挂载候选只读目录为/workspace，无仓库、研究资料或其他运行可见；模型仅可候选读取命令。单独临时认证目录，运行后移除。反思工具全部关闭。先零模型检查隔离、只读、请求硬上限和无工具限制，然后冻结版本。除明确失败策略外按固定顺序继续；计量/隔离不可靠或反思候选阻断则停止后续。

报告限制：同开发案例反思后回测不能证明泛化，两次重复仅描述波动；质量为执行AI代理评价，不是独立人工复核。不运行维护、测试评分、ReAct或官方GEPA。
