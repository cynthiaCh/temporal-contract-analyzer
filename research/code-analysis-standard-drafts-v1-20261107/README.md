## “标准”来自哪里

- **源码事实**：从冻结的任务和源码逐项读取，不能仅凭名称推断。
- **历史补丁事实**：从该次 `patch.diff` 读取；它不是原始实现，也不是参考答案。
- **实际行为**：从该次归档测试的实际值、事件轨迹读取。
- **预期行为**：来自案例已有测试，但仍需人工核实是否有任务、文档及接口语义依据。测试预期不自动等于已证明正确的业务要求。
- **原因判断**：单独写明依据与未知，不因某条测试失败就断言唯一根因。

来源均为 `development-feedback-mechanism-v1-20261106/evidence/U1`、`evidence/U2` 的原始归档，另参考其 `evidence-key.json` 核对关联。两案例已用于开发研究，不能据此宣称独立泛化。
