# 冻结经验后的同题对照：调用前协议

本批来源为 query-paused-same-case-low-20261108_140200 的 manifest 实际指定案例 query-paused-initial-fetch-10266-vanilla。旧批次 AUTO 开发0/2（26/29、26/29），AUTO_EXP 开发1/2（27/29、29/29）；旧准入失败及停止结果不变。

这是看过开发结果后提出、在本批正式调用前冻结的探索性后续实验。唯一研究协议变化是：开发存在改善信号的经验，即使出现局部退步，也允许进入后续对照。是否有价值由整体通过、分项得失和成本共同判断。不改变正确答案、原评分器、29项要求、完整通过标准、历史失败或退步记录。不是未见案例的独立测试，不是整个研究过程的事先预注册。

## 冻结条件

A/AUTO：旧实际 AUTO prompt 原样复用（包含原任务、固定自动 Contract、公共工具/输出/外部自动归档说明）。B/AUTO_EXP：A 原文加两个换行再加 NEW_EXPERIENCE.md 全文，逐字节核对旧开发回验 prompt。不重新提取 Contract，不生成或改写经验，不提供开发补丁、评分解释或反馈。不调用 GEPA、反思、模型评委，不更新生产经验库。

每次从同一原始候选复制独立可写工作区、独立 CLI 会话，不带任何其他会话记忆。运行器原样复用，CLI/hash、工具权限、配置、输出格式、Node与评分依赖版本均核验。模型 gpt-5.6-terra/low，priority；每次最多24底层请求、600秒、16MiB stdout，简短 JSON report 最多6000字符。并发1，最多6会话/144请求/累计会话3600秒，无隐藏预跑、补跑、自动重试或第三组。CLI effort 声明可核对、hook model 可核对；服务端 effort/路由无独立证明，此限制与旧批一致。

调度用 random.Random(20261108) 在三个重复块中分别打乱 A/B，顺序写入 schedule.json。该种子只控制调度，不控制模型采样。不依据中途质量改变顺序或取消正常槽位。外部评分仅在模型停止后对归档最终候选执行，写入隔离归档；六槽结束后统一分析，不反馈后续模型。

## 生命周期与异常

原样复用 runner.session、runner.command、runner.verify/source_proof、Archive.prepare/finalize/collect/write_manifest、GuardServer 和旧 score 回调（评分政策不变）。机械归档完全由 Python 完成，模型只修业务、必要自验和输出原协议简报。宿主快照/任务/prompt/config、事件/stderr、请求/工具/token、最终快照、patch.diff、原始回答、评分及归档异常都在模型挂载工作区之外。隔离保留合法读写/验证工具，不增加 shell 关键字黑名单。模型超时/退出仍归档；diff 0无差异、1正常有差异、其他为异常；不向模型追加归档修复请求，不删除其新增文件。评分输入必须与最终候选摘要相同，评分前后摘要相同。

正常行为失败和新增保留行为损失继续执行剩余槽位。资源耗尽沿用旧 runner 的 model_resource_limit 规则，单列报告；在计量/基础设施及评分有效时保留为有效行为结果，不能排除来提高成功率。隔离、输入版本、计量失真立即停止；连续两次基础设施异常停止；关键归档/评分交接完整性损坏停止并注明原因。每槽保存实际计量、所有已启动槽及未启动槽，不补齐、不重试，不用缺失代替成功或失败。

## 预先固定的分析

主要指标为每组完整通过数/有效分母及 B-A 通过率差。有效指基础设施/请求计量、归档、固定外部评分及候选交接有效；正常代码失败、资源耗尽、无改动不据此剔除。无有效评分的异常单列，不代填结果。JSON格式/源码阅读证据另外披露，不事后新增剔除标准。

完整保存每槽29项行为向量、目标三项（training-targets.json）、每项通过次数、相对原始候选21项原正确行为的损失，以及块内B相对A的得失（块不是共同采样种子）。审阅每份补丁和额外文件，注明无据改动与可能影响，不凭后缀删除或判垃圾。

分组报告底层实际 started/completed/blocked、input/cached/output/reasoning token、工具调用与会话秒数。缺失token只报已观测小计和缺口，不伪造0；缓存和reasoning是各自总量子集，不重复相加。主控聊天自身平台计量不可见，不混入维护调用成本，不声称为0。

B完整通过率更多且分母可比：只报告“本次小样本观察到同题整体修复增量”，完整列退步及成本；整体相同而分项更好：仅局部改善；B更少：本轮不支持整体收益；有效运行不足/分母不同：明确受限并同时给分母与异常，不只比较通过个数。各3次不支持稳定有效、统计显著、新题泛化或自进化普遍成功/失败。开发0/2与1/2单独展示，不并入本批分母。不能只选B成功补丁。完成六槽或触发异常停止即结束，不追加经验、训练或其他案例。
