     1	# Transit stop lookup
     2	
     3	A shared per-key query cache provides subscribe(key,options) -> unique observer
     4	handle, unsubscribe(handle), online(boolean), focus(boolean), snapshot(key),
     5	and dispose() of observer scopes. Queries retain status (pending/success/error),
     6	fetchStatus (idle/fetching/paused), and data. queryFn receives a lazy signal
     7	accessor. Each actual access records consumption; each fetch owns its controller
     8	and completion. Completion is asynchronous; initial online entry is synchronous,
     9	paused continuation resumes on a Promise turn. First start uses network mode;
    10	continuation also needs focus. 'always' can run offline; 'offlineFirst' allows
    11	first offline entry but retry can pause. Retries use explicit scheduler handles.
    12	Multiple observers share one fetch. Unconsumed active work can finish into cache
    13	after its view departs; consumed work is physically abortable. Cancellation
    14	reverts previous query data/status and settles the originating attempt. Late
    15	fulfillment cannot become a new attempt's data. Unknown unsubscribe is inert.
    16	The component owns observer scope; the cache remains outside individual views.
    17	Dependency versions and build/test configuration are outside the repair scope.
    18	
    19	Embedding API: bind registers a native callable; Environment.call
    20	provides newAttempt(key,number), abort(key,number), request(key,number, lazy-read
    21	token, completion token), defer(callback token), schedule(callback token,delay).
    22	The request host calls queryFn with an actual AbortSignal property. Reading it
    23	invokes the native consumption closure synchronously; Promise settlement later
    24	invokes the native completion with {ok,value}. All observer, retry, cancellation,
    25	state and cache logic executes in the target language. No native JS Promise or
    26	DOM claim is made. Native object identity binds query and attempt generations;
    27	wire handles only identify injected callbacks. 
    28	Module cache and EventTarget subscription handles; actual Node16 promises
