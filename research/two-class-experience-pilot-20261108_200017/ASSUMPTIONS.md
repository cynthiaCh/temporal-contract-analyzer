# Decisions before implementation

- User protocol overrides design-only run_enabled=false in the v1 proposal. No old scheduler is imported or started.
- The old schema envelope {report:string} is retained; preanalysis/reflection report contains one JSON object parsed without another model call. Contract text alone is sent to both maintenance arms. Classification and route metadata remain external.
- Applicability uses a fixed generic predicate vocabulary and literal source/document evidence. This checks current mechanisms and policy, not whether the candidate already implements the desired fix. Unknown or contradictory premises abstain. Semantic classifications are the single preanalysis model's judgments, not proven by AST.
- Reflection supplies original text plus predicate requirements/exclusions from that vocabulary. No hand editing or second candidate. Development revalidation receives the candidate verbatim; admission decision remains evidence-based and separately recorded by the executing agent.
- Scoring uses manifest original ungranted rules and original probe. Reuse calibration only when exact candidate/task/oracle hashes match. Node18 runtime inherited from prior calibration; manifest Node16 discrepancy disclosed, Python is 3.8.10. No dependency installation.
- An invalid preanalysis yields unknown and no auxiliary Contract (empty shared Contract), with raw result archived; no retry. Infrastructure/integrity stopping rules still apply. No source-read evidence means extraction is invalid.
- Reflect only if baselines expose a failure and a known primary class. At most one reflection per observed class, total two. Failed/unsupported candidate leaves class empty. Revalidation is one slot, never repeated.
- A failed experimental maintenance result from normal timeout/request cap is scored and retained. Infrastructure failures retain slot and unchanged/partial candidate; two consecutive stop. Isolation/input/meter/archive drift stops immediately.
- Prompt material uses only task, candidate relative source/docs, AST, taxonomy and the fixed predicate vocabulary; no manifest/cluster/source ID, scorer, prior scores, or reference patch. Reflection receives training-only policy/score artifacts and actual patches, never references.
- Summary reports unknown tokens/cost as null. Offline fake sessions are explicitly fixtures, excluded from paid session/request totals. Existing source exposure is permanent.
