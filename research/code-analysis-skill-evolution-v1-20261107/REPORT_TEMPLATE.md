# 分析报告输出协议

交付是代码分析报告。原维护任务只作为分析背景，不执行它，不修改任何候选文件，不运行测试、维护评分、检索历史研究记录或产生代码补丁。

只分析当前隔离工作区的候选源码和文档。允许使用工具读取、列出和检索这些文件。不得读取人工标准、确认记录、原始评分、隐藏测试、参考修复、历史模型报告/技能反馈或其他运行输出。

返回JSON对象，唯一字段为report。report用以下六部分组织：

1. 任务目标和保留行为
2. 源码事实及引用
3. 关键事件关系及依据
4. 行为要求及依据
5. 未知项
6. 建议验证范围

以候选路径:行号引用，提供简短、可检查的依据，不输出完整内部思维链。不因不能确认某个要求而补全答案。不把建议验证写成已验证。

report总长不超过6000个Unicode字符，含标题、空白、标点和英文。不会在归档时裁剪；超限、缺字段和失败输出原样保存，标记格式失败，不重生成。
