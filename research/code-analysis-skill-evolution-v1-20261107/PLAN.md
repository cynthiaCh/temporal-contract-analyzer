## 评价适用性

六类分别记录：正确覆盖、部分覆盖、遗漏、与证据矛盾、无依据要求/原因、合理未知。另核对引用准确性、方向/归属及保留内容，不加总掩盖关键关系错误，不按词句或字数给分。

标准含历史补丁及评分，而模型只获得原始task/source。因此不能要求模型复述未提供的历史实际输出、补丁状态或唯一故障结论。U1-A2只能用于其所分析版本的准确界定，未见补丁时对历史版本保持未知是合理的；不能扣“没有描述历史补丁”。U2历史generation/mounted赋值顺序同理。历史实证只能研究侧诊断，不强迫报告给出未知事实。需要确认的R2等政策先排除确定性判错；建议查证某政策与断言该政策已确定需分开。

完成八份报告后随机匿名ID，标签映射单独保存；当前Agent已知条件时一律未盲化代理审查。用同一规则填表并冻结后解盲汇总；逐案例逐重复检查K1新增内容和K0原正确内容的丢失。无独立人工盲评、无LLM judge、无显著性或泛化结论。
