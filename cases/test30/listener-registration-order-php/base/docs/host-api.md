The channel exposes connect(mode), emitUpdate(), target and decode(value). It emits immutable token:bootstrap or token:update values. Decode may complete now or later. Navigation exposes select(channel,mode), hide() and framework disposal. Publish(value,navigation) can synchronously navigate or hide. The independent metrics observer uses its own source and deliberately connects before attaching its listener, collecting updates only. Preserve these APIs and payloads.
Native counterparts use Channel.listen/detach/connect/update and Workspace.select/hide (Go exports Listen/Detach/Connect/Update/Select/Hide). Injected Environment supplies defer(callback), resolve(kind,key,scalar,completion) and output(kind,key,value); Java returns CompletableFuture<String>, Python concurrent.futures.Future, PHP uses Closure, Ruby blocks, Go typed funcs. Immediate completion executes inline; defer is controlled FIFO scheduling. Native channel emission/listener registry, subscription/visit state and publish decisions execute in the target runtime. The hidden wire only transports host calls/completions; it supplies no validity policy.
