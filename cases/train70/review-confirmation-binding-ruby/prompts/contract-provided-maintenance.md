The library acquisition review editor currently writes on every keystroke. Coalesce edits using the trailing-task utility: after a 120 ms quiet interval write only the latest text in that editing burst. Subsequent bursts must continue to save. Preserve other supported behavior and the synchronous public interfaces. The adjacent search preview is outside this maintenance change.

Preserve the following coordination relationships while coalescing saves.
An accepted review belongs to the document, text, and editor visit at submit entry.
Its text is persisted before enqueue, and exactly one original receipt is retained
and returned even if integrations navigate. Store writes and queue enqueue both
invoke integrations synchronously; either can close, switch, or reopen a visit.
A confirmation outlet captures the visit active at binding time. It must represent
the accepting visit, and may show the receipt only while that visit remains active.
Validity at output cannot correct an outlet that was already bound to a newer visit.
Preserve a live origin's confirmation and future edits/submissions. Leaving commits
accepted draft text before navigation returns, after retiring the departing badge;
navigation requested later takes precedence. A consumed batch cannot fire again,
and new work accepted by a callback retains its own quiet interval. Preview hide
still discards pending work; its delay remains unchanged unless authorized.

Renderers are passive sinks. Store and queue deliveries use a snapshot of subscriptions but skip subscriptions removed before their turn. A new subscription waits for the next event. Documents and text are immutable string values; visit and acquired capability identities are separate from the document key. No network acknowledgement or asynchronous callback assumption is introduced.
